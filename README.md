# الخروس — منصة أهالي ضاحية الخروس

واجهة متكاملة لمنصة أهالي ضاحية الخروس (مدينة الذيد · إمارة الشارقة): فعاليات، أخبار، ألبومات، سوق، ملتقى، مسابقات، تراث، تعليم، ودليل.

النسخة الحية: [khuoros.ae](https://khuros.ae/)

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```
